* ESCAPE

You can watch the full simulation of the Square case [[https://youtu.be/0RpVIt6iqHw][here]].

* Installation

You can install Escape with the following command in the terminal:

#+BEGIN_SRC bash
git clone https://github.com/juliocesar-ramirez/cplus-version.git
cd cplus-version
make
source bashrc
#+END_SRC

* Requirements

- Language: C++ (C++17 support is required)
- Compiler: GCC 9.4 or higher / Clang 10.0 or higher
- Build tools: 
  - GNU Make 4.2.1 (Makefile)
  - Operating system: Ubuntu 20.04.6 LTS
- Optional tools:
  - gnuplot: used by the program to write the evacuation plots (without it the plots are skipped and the simulation still runs)
  - Python 3 with matplotlib, progressbar2 and screeninfo, and ffmpeg: used by the post-processing scripts in each tutorial
